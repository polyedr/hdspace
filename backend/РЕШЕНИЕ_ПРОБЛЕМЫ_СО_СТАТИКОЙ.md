# Решение проблемы со статическими файлами Swagger UI

## 🐛 Проблема

**Симптом:** Страница http://localhost:18000/api/v1/schema/ отображалась пустой (белый экран)

**Причина:** Gunicorn (в отличие от `runserver`) не отдает статические файлы автоматически в dev режиме

## ✅ Решение

Установлен и настроен **WhiteNoise** - middleware для отдачи статических файлов через Gunicorn.

### Что было сделано:

1. **Добавлен WhiteNoise в зависимости:**
   ```
   requirements-docker.txt:
   + whitenoise==5.3.0
   ```

2. **Добавлен в MIDDLEWARE:**
   ```python
   MIDDLEWARE = [
       "sesame.middleware.AuthenticationMiddleware",
       "django.middleware.security.SecurityMiddleware",
       "whitenoise.middleware.WhiteNoiseMiddleware",  # ← Добавлено
       "django.contrib.sessions.middleware.SessionMiddleware",
       ...
   ]
   ```

3. **Настроено хранилище статики:**
   ```python
   STATICFILES_STORAGE = 'whitenoise.storage.CompressedManifestStaticFilesStorage'
   ```

4. **Пересобрана статика:**
   ```bash
   docker-compose exec web python manage.py collectstatic --noinput --clear
   # Результат: 236 static files copied, 680 post-processed
   ```

## 🧪 Проверка

```bash
# Проверка статических файлов
curl http://localhost:18000/static/drf-yasg/swagger-ui-dist/swagger-ui.css
# HTTP 200 ✅

curl http://localhost:18000/static/drf-yasg/swagger-ui-dist/swagger-ui-bundle.js
# HTTP 200 ✅

# Проверка Swagger UI
curl http://localhost:18000/api/v1/schema/
# HTTP 200 ✅ (теперь с контентом!)
```
