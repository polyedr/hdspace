## ⚠️ Возможные проблемы:

### 1. Node.js версия

**У вас:** Node.js v22.15.1  
**Рекомендуется проектом:** Node.js v16.19.0

Если будут проблемы с совместимостью, используйте **nvm** для переключения:

```bash
# Установка nvm (если нет)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# Установка Node.js 16
nvm install 16
nvm use 16

# Запуск приложения
npm run dev
```

## 🐛 Troubleshooting:

### Ошибка при запуске:

```bash
# Очистка
rm -rf node_modules package-lock.json
npm install

# Запуск снова
npm run dev
```

### Ошибки CORS:

Если frontend не может подключиться к backend:
1. Проверьте что backend на 18000 порту
2. Проверьте CORS настройки в Django (должны разрешать localhost:8080)

### Порт 8080 занят:

Измените порт в package.json:
```json
"dev": "vite --open --port 8081"
```
